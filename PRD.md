# College Coordination Copilot — PRD

## Problem

College group chats contain important commitments mixed with casual conversation, questions, changes, and unclear statements.

Students can easily lose track of:

- who agreed to do something
- what they agreed to do
- when it is due
- what is still unresolved

## Solution

College Coordination Copilot analyzes messy conversations and converts them into a structured coordination board.

## Target Users

College students working on:

- hackathons
- assignments
- group projects
- presentations
- college events

## Core Features

1. Conversation input
2. Gemma 4 analysis
3. Commitment extraction
4. Deadline extraction
5. Status detection
6. Source traceability
7. Needs Clarification
8. Editable local status

## Non-goals

Do NOT build:

- authentication
- database
- WhatsApp API
- Discord API
- calendar integration
- notifications
- realtime collaboration
- mobile application
- vector database
- RAG
- multi-agent architecture

Keep this a one-day hackathon MVP.

## Success Criteria

A user should be able to:

1. Paste a messy group conversation.
2. Click Analyze.
3. Receive structured commitments.
4. See unresolved/ambiguous items.
5. Trace every result back to its source message.
